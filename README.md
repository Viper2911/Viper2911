## 💫 About Me

### ⚡ What I'm Building & Focused On

- **Autonomous AI Research Discovery System** — Multi-agent state machine (Review, Hypothesis, Code, Critic) built with LangGraph, Llama 3.1, Milvus RAG, and SQLite checkpointing.
- **LLM-Guided Causal Inference Engine** — Estimating causal treatment effects on Olist e-commerce data using Propensity Score Weighting, Hajek-IPTW, refutation testing, and E-values.
- **Smart City Traffic Analytics** — Edge AI pipeline using custom-trained YOLOv8 tracking, radar-free pixel speed estimation, and OpenCV geometric lane masking.
- **Skin Cancer Lesion Classification System** — Lightweight 5-stage custom CNN on HAM10000 (96.75% validation accuracy) with DullRazor/Telea artifact removal and Grad-CAM heatmaps.
- **IntelliSQL Translation Application** — Natural language-to-SQL engine powered by the Gemini API, vector schema embeddings, FastAPI, SQLite, and Streamlit.
- **Fatty Liver Disease Diagnostic System** — Stacking Classifier (Random Forest, XGBoost, SVM + Logistic Regression) with SMOTE balancing and SHAP clinical explainability.
- **Multi-Output Stock Forecasting Model** — LSTM time-series pipeline predicting next-day low, high, and close prices with macroeconomic indicators and TextBlob sentiment.
- **Competitive Programming & ML Research** — Solving algorithmic problems on Codeforces (`Viper777`), competing on Kaggle (`aadil007`), and pursuing B.Tech CSE at VIT Chennai.
